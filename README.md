# القرآن الكريم — مصحف المدينة

تطبيق Android مخصص لقراءة **مصحف المدينة فقط**.

## شكل القراءة

- 604 صفحة ثابتة بنفس ترتيب مصحف المدينة.
- لا يوجد وضع نص يعيد ترتيب الآيات حسب حجم الشاشة.
- الصفحة تظهر كوحدة واحدة مثل المصحف الورقي.
- السحب بين الصفحات، والضغط على الصفحة لإظهار أو إخفاء أدوات التنقل.
- يتذكر آخر صفحة وصل إليها القارئ.

## بناء APK

يتم بناء APK تلقائيًا بواسطة GitHub Actions عند كل تحديث على الفرع `main`.
ملف البناء النهائي يظهر كـ Artifact باسم:

`quran-kareem-madinah-apk`

## مصدر صفحات المصحف

أثناء البناء يتم جلب صفحات WebP من مشروع Daily Quran المفتوح المصدر:
`Bsracc/daily-quran`.

المشروع المصدر مرخص MIT ويذكر أن صور مصحف المدينة مشتقة من أصول Quran.com / quran_android.
صفحات المصحف نفسها لا تُخزَّن في هذا المستودع، بل تُجلب أثناء عملية البناء.
